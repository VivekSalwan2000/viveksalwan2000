### `$` ls projects/

#### [Festify](https://github.com/VivekSalwan2000/festify) — event discovery and ticketing

Attendees browse events and buy tickets with tiered pricing and promo codes; organizers get a dashboard with attendee analytics. Runs serverless on Firebase with AI-generated posters via DALL·E 3, QR-code ticket verification, and Google Maps integration — deployed static to GitHub Pages with no build step.

#### [NewsHub](https://github.com/VivekSalwan2000/NewsHub---Android-News-App) — Android news reader

Live headlines, category browsing, search, offline bookmarks, and in-app reading via WebView. Retrofit/OkHttp networking with lifecycle-safe cancellable calls, a Room database for offline storage, and Hugging Face integration for on-demand article summaries. Ships with 13-language support.

#### [VillageWar](https://github.com/VivekSalwan2000/Game-War-Advanced-OOPs) — networked strategy game

A JavaFX desktop client talking to an authoritative multi-client TCP server over object serialization: build villages, train armies, contest territory. Applies MVC/MVVM, Abstract Factory, and Adapter patterns across a from-scratch domain model, backed by 28 unit tests and a JDK 17/21 GitHub Actions CI matrix.
