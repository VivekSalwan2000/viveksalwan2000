### `$` ls projects/

**[🎪 Festify](https://github.com/VivekSalwan2000/festify)**
Full-stack event discovery and ticketing platform — attendees browse and buy tickets with tiered pricing and promo codes, while organizers get a dashboard with attendee analytics. Built serverless on Firebase (Auth, Firestore, Storage), with AI-generated event posters via OpenAI's DALL-E 3, QR-code ticket verification, and Google Maps integration. Deployed as a static site to GitHub Pages, no build step required.
<br/><img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black" /> <img src="https://img.shields.io/badge/Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=black" /> <img src="https://img.shields.io/badge/OpenAI_API-412991?style=flat-square&logo=openai&logoColor=white" /> <img src="https://img.shields.io/badge/Jest-C21325?style=flat-square&logo=jest&logoColor=white" />

**[📰 NewsHub — Android News App](https://github.com/VivekSalwan2000/NewsHub---Android-News-App)**
Production-ready Android news reader with live headlines, category browsing, search, offline bookmarks, and in-app reading via WebView. Built on Retrofit/OkHttp networking with lifecycle-safe, cancellable API calls, a Room database for offline storage, and Hugging Face integration for on-demand article summaries. Supports 13 languages.

**[⚔️ VillageWar](https://github.com/VivekSalwan2000/Game-War-Advanced-OOPs)**
Networked strategy game — build villages, train armies, and battle for territory — with a JavaFX desktop client talking to an authoritative multi-client TCP server over object serialization. Applies MVC/MVVM, Abstract Factory, and Adapter patterns across a from-scratch domain model, backed by 28 unit tests and a JDK 17/21 GitHub Actions CI matrix.
